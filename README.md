# Moch Syafaat Ziqri - Portfolio

Bilingual portfolio: web applications, workflow automation, digital products and GovTech.

Website: https://ziqri7.github.io/

## Development

Requires Node.js 22 or later. No dependencies to install.

    npm run dev

Local preview: http://127.0.0.1:4297/

    npm run check
    npm run build

GitHub Actions builds and publishes only `dist/` to GitHub Pages when `main` changes.
Edit bilingual text in `src/content.mjs` and `src/home.mjs`.

Case illustrations use synthetic data. Private application code and operational records are not included.
Development uses AI assistance with human review.

## Fonts

Space Grotesk, IBM Plex Sans, IBM Plex Mono and JetBrains Mono are self-hosted.
Their SIL Open Font Licenses are included in `src/assets/`.
